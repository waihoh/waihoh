# Wai Hoh Tang
### Machine Learning Researcher | Applied AI | Deep Learning

I develop and evaluate machine learning methods for challenging problems in computer vision, scientific imaging, generative modelling and quantitative data analysis.

With a PhD in Statistics and six years of postdoctoral research experience, I combine statistical foundations with hands-on deep learning research. My work spans neural network architecture development, experimental design and evaluation, independent research direction, and industry-facing machine learning projects.

## Areas of Focus

- **Deep Learning & Computer Vision** — CNN architectures, transfer learning, image analysis and model evaluation.
- **Generative Modelling** — GANs, VAEs and synthetic tabular data generation.
- **Scientific Machine Learning** — Deep learning for scientific imaging, inverse problems and time-series modelling.
- **Statistical Learning & Model Evaluation** — Statistical inference, uncertainty quantification and rigorous empirical evaluation.
- **Quantum Machine Learning** — An emerging interest 🌱; exploring quantum computing and its potential applications to machine learning.

## Selected Research Implementations

- **[ImFCSNet & FCSNet](https://github.com/waihoh/ImFCS_FCSNet_ImFCSNet)** — Training code for deep-learning models that estimate diffusion coefficients from fluorescence microscopy data. Related work was published in *Biophysical Journal* (2024; cover article).
- **[PICProp](https://github.com/ShenQianli/PICProp)** — Official implementation of *Physics-Informed Confidence Propagation for Uncertainty Quantification*, published at NeurIPS 2023. I co-authored the paper.
